# Sales Performance Analysis

## 📌 Project Overview

This project analyzes retail sales data to identify business opportunities, improve profitability, and support data-driven decision-making.

## 🎯 Objectives

- Analyze sales performance
- Identify top-performing products
- Evaluate customer segments
- Examine regional performance
- Provide actionable business recommendations
